lc-ns-kmp documentation
=======================

**Linearly Constrained Null-Space Kernelized Movement Primitives** — C++ library
with Python bindings for constrained trajectory generation from demonstrations.

Primary citation (please prefer this over citing the software alone):

  Padalkar, A., Stulp, F., Neumann, G., & Silverio, J. (2025).
  *Towards Safe and Efficient Learning in the Wild: Guiding RL With Constrained
  Uncertainty-Aware Movement Primitives.* IEEE RA-L.
  https://doi.org/10.1109/LRA.2025.3566599
